# Training

Сайт для прорешки тем по математическому анализу: **пределы, производные, интегралы**.
Оформление — «полужидкое стекло»: матовые стеклянные панели над медленно текущим цветным фоном на миллиметровке, светлая и тёмная тема.

- 3 тренажёра, 43 темы, 407 задач с проверкой ответа
- в каждой теме: теория → разбор примера → практика, подсказки и решения
- калькулятор с пошаговым решением, генератор задач трёх уровней, контрольная из 10 задач
- 6 PDF: шпаргалка и подробный разбор к каждой теме
- прогресс хранится в браузере (localStorage), регистрации нет

## Структура

```
index.html          главная: вкладки «Тренажёры», «Материалы», «О сайте»
limits.html         тренажёр «Пределы»
derivatives.html    тренажёр «Производные»
integrals.html      тренажёр «Интегралы»
pdf/                шпаргалки и разборы
assets/glass.css    общий стиль «жидкое стекло» (токены, фон, панель навигации, кнопки)
assets/home.css     стили главной
assets/trainer.css  стеклянное оформление тренажёров (поверх их собственных стилей)
assets/site.js      тема, навигация, прогресс на главной, сброс прогресса
```

Вставки сайта в файлы тренажёров помечены комментариями `<!-- Training: … -->`; логика тренажёров не менялась.

## Запуск

Сборка не нужна. Локально:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
Через минуту сайт будет на `https://xtop1337.github.io/Training/`.
